## 📌 Executive Summary

Full-stack MERN developer portfolio built for **Ahmad Imran**. Designed with modern cybernetic dark aesthetics, high-contrast light mode styling, interactive developer mascot graphics, and real-time REST API integration.

### 🌟 Key Highlights

- **☀️ / 🌙 Light & Dark Mode Switcher**: Smooth theme transitions with custom CSS variables and persistent `localStorage` memory.
- **💬 Interactive AI Portfolio Assistant**: Embedded NLP chatbot widget powered by Express REST API (`POST /api/ai-assistant`) answering questions about Ahmad's experience and stack.
- **📄 1-Page Official PDF CV & Instant File Downloader**: Printable A4 single-page CV matching official credentials with 1-click PDF print and `.txt` file downloading.
- **✉️ Functional Contact Hub**: REST API powered contact form (`POST /api/contact`) with real-time feedback toast notifications.
- **🖼️ Profile Photo Integration**: Featured profile photograph with glowing 3D glassmorphic card and orbiting tech badges.

## ⚙️ Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ahmad2912-cpu/ahmadimranportfolio.git
   cd ahmadimranportfolio
   ```

2. **Install dependencies**:
   ```bash
   cd server && npm install
   cd ../client && npm install
   ```

3. **Run Client & Server concurrently**:
   ```bash
   npm run dev
   ```

4. **Access ports**:
   - Frontend React App: `http://localhost:3000`
   - Express REST API: `http://localhost:5000`
